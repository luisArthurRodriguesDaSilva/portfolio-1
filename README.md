# Catálogo de Apps

Aplicativo corporativo de governança de aplicativos e componentes (Power Apps + SharePoint), com uma **demo interativa recriada em HTML**.

> Todos os nomes de empresa, pessoas, áreas, aplicativos, listas, links e identificadores desta página são **fictícios**. Nenhum dado real foi utilizado.

## O que a demo mostra
- Catálogo de aplicativos e de componentes, com filtros, ordenação e detalhes
- Cadastro com vínculos por link e fluxo de aprovação
- Dashboard com quatro visões e seis filtros
- Configurações sem código: listas de valores, tipos, menu e administradores
- Visão por perfil e representação de usuário

## Como abrir
Acesse a página publicada pelo GitHub Pages. Funciona em desktop e celular.
